# ⏱ KUTMA — Navbatsiz rejalashtirish platformasi

Samarqand shahridagi kafe, restoran, sartaroshxona va go'zallik salonlarining
**hozirgi bandligini real vaqtda** ko'rsatadigan platforma.
Borishdan oldin bo'sh joy borligini bilib oling — navbatda kutmang!

🌐 **Sayt:** https://samiyevasitora2005-lgtm.github.io/kutma.uz/

## Imkoniyatlar
- 🟢 **Real vaqtdagi bandlik monitoringi** — bo'sh stol/usta soni va bandlik foizi
- 🚶 **Majburiyatsiz tashriflar** — oldindan bron qilmasdan, qulay vaqtda boring
- 🍽 **Jonli menyu** — taomlarning hozir bor yoki qolmaganligini ko'ring
- 🗺 **Marshrut** — "Hozir borish" tugmasi Google Maps'da yo'lni ochadi
- 🏪 **B2B admin panel** — biznes egalari bo'sh joylar va menyuni boshqaradi
- 💳 **Narxlar** — foydalanuvchilar uchun 9 900 so'm/oy, biznes uchun 250 000 / 400 000 so'm/oy

## Sahifalar
| Sahifa | Vazifasi |
|---|---|
| `index.html` | Asosiy ekran: qidiruv, kategoriyalar, yaqin joylar |
| `place.html` | Joy tafsilotlari: bandlik grafigi, jonli menyu |
| `admin.html` | Biznes egalari uchun boshqaruv paneli |
| `pricing.html` | Narxlar siyosati |
